# Problem 12: Highly Divisible Triangular Number

> Source: <https://projecteuler.net/problem=12>

The sequence of triangle numbers is generated by adding the natural numbers. So the $7$th triangle number would be $1 + 2 + 3 + 4 + 5 + 6 + 7 = 28$. The first ten terms would be:

$$1, 3, 6, 10, 15, 21, 28, 36, 45, 55, \dots$$

Let us list the factors of the first seven triangle numbers:

$$\begin{align}
\mathbf 1 &\colon 1\\
\mathbf 3 &\colon 1,3\\
\mathbf 6 &\colon 1,2,3,6\\
\mathbf{10} &\colon 1,2,5,10\\
\mathbf{15} &\colon 1,3,5,15\\
\mathbf{21} &\colon 1,3,7,21\\
\mathbf{28} &\colon 1,2,4,7,14,28
\end{align}$$

We can see that $28$ is the first triangle number to have over five divisors.

What is the value of the first triangle number to have over five hundred divisors?

### Approach

Walk through the triangle numbers in order and count the divisors of each one through its two coprime halves.

**1. Split each triangle number into coprime halves**

The $n$th triangle number is

$$T_n = \frac{n(n + 1)}{2}$$

$n$ and $n + 1$ share no common factor, and halving the even one keeps it that way, so $T_n = a \cdot b$ with $\gcd(a, b) = 1$:

- $n$ even: $a = n / 2$, $b = n + 1$
- $n$ odd: $a = n$, $b = (n + 1) / 2$

For example, $T_7 = 28 = 7 \cdot 4$ and $T_8 = 36 = 4 \cdot 9$.

**2. Multiply the divisor counts**

For coprime $a$ and $b$, every divisor of $ab$ is a divisor of $a$ times a divisor of $b$ in exactly one way, so

$$d(ab) = d(a) \cdot d(b)$$

This only holds for coprime numbers: $d(2 \cdot 2) = d(4) = 3$, not $d(2) \cdot d(2) = 4$.

**3. Count divisors by prime factorization**

If $m = p_1^{e_1} p_2^{e_2} \cdots$, a divisor picks each exponent from $0$ to $e_i$, so

$$d(m) = (e_1 + 1)(e_2 + 1) \cdots$$

The exponents come from dividing out each factor from $2$ upward while $\text{factor}^2 \le$ the remaining number, as in Problem 3.
Anything above $1$ left at the end is a single prime factor, which contributes a factor of $2$.

Working on the halves instead of $T_n$ keeps every number factorized close to $n$ rather than $n^2 / 2$.

**Check with the example** (over $5$ divisors): $T_7 = 28 = 7 \cdot 4$, and $d(7) \cdot d(4) = 2 \cdot 3 = 6 > 5$, while every earlier triangle number has at most $4$ divisors.
